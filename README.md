# ComfyUI-Suski-Prompt-Vault

一个内嵌在 ComfyUI 节点内的三栏提示词管理工作台。主要用于管理个人的高频提示词、结构化组合模板，并在画布上直接拼装、排序和调权。

---

## 设计意图

开发这个插件主要是为了解决个人在日常搓提示词过程中的几个实际操作问题：

1. **保留调试心流，避免来回改坏预设**
   * 提示词调试是一个频繁试错的过程。如果直接改本地词库容易改乱；如果在普通的长文本框里反复加减词和逗号，很容易迷失。
   * 因此设计了“独立草稿”机制：在节点中对词条的修改只作用于当前节点，可以随时一键还原回原始预设；只有测试满意了，再手动点击入库。
2. **支持“穿插式”的模板结构**
   * 很多预设本质上是一套前后呼应的框架（例如“做饭”主题包含：前端的光影/构图，加上后端的动作/姿势）。
   * 传统打包预设一旦载入就变成死板的一整块，无法在中间插入内容。这里将“组”设计为带有几何连线轨道的松散组合，组员载入后，允许将其他独立词条（如角色、道具）直接拖拽插入到组内，连线会自动穿透，既能保持成组的视觉关联，又不限制词序调整。
3. **减少操作弹窗**
   * 拒绝浮窗或独立弹窗的形式，直接将三栏界面挂载在节点主体内（默认尺寸 1120×620），选词、排序、改词全部在画布视野内完成。

## 主要功能与交互

### 1. 三栏工作区
* **左栏（提示词库）**：
  * 支持分类筛选、收藏夹筛选与关键词搜索。
  * 提供“词条视图”与“组合视图”两种浏览模式。
  * 单击即可加入中栏；若已加入，再次点击则移出。
* **中栏（已选列表）**：
  * 显示当前节点最终参与拼接的词条序列。
  * **滚轮调权**：鼠标悬停在磁贴权重标记上，上下滚动滚轮以 `0.1` 为步长增减权重。
  * **一键静音**：点击眼睛图标可以禁用单条词条，使其不参与最终拼接，便于对照测试。
  * **多选与排序**：按住 `Shift` 可多选词条；支持单条或批量拖拽调整前后顺序。多选后可就地打包新建为组合。
  * **轨道连线**：属于同一个组的成员左侧会显示发光树状连线，中间插入其他词条时以穿透线连接。
* **右栏（词条详情与实时编辑）**：
  * 选中中栏的某个词条后在此显示详情，可直接修改名称、分类和提示词内容。
  * **状态指示**：若内容与词库预设不一致，会提示“草稿未入库”。
  * **恢复原预设**：放弃当前修改，重置为引用的词库内容。
  * **保存至预设库**：将当前的修改正式同步回 `library.json`。

### 2. 多节点实时同步与防冲突
* 画布上放置多个该节点时，任意节点对词库的修改（增删改）会通过本地 WebSocket 广播，其他节点会自动热更新词库，无需刷新网页。
* 数据写入采用线程锁与临时文件重命名（原子写入），防止并发或意外中断损坏 JSON 文件。
* 针对 ComfyUI Nodes 2.0 做了样式隔离与属性保护，避免破坏侧边栏宽度。

## 节点规格

* **节点类名**：`PromptVaultSelector`
* **显示位置**：`Prompt / Conditioning`

### 输入 / 输出端点

| 插槽 | 名称 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| **Input** | `prepend_prompt` | `STRING` | *(可选)* 前置提示词，拼在所有磁贴最前面 |
| **Input** | `append_prompt` | `STRING` | *(可选)* 后置提示词，拼在所有磁贴最后面 |
| **Input** | `selected_tiles_data`| `STRING` | *(隐藏)* 磁贴序列化数据通道 |
| **Output**| `prompt` | `STRING` | 最终生成的提示词文本 |

### 拼接规则
1. 忽略处于禁用（静音）状态的词条。
2. 权重等于 `1.0` 时直接输出原内容；不等于 `1.0` 时输出格式为 `(prompt:weight)`。
3. 自动合并冗余逗号、修剪多余空格及首尾标点。

## 本地数据与备份

所有数据均保存在插件本地目录下：
* **词库数据**：`ComfyUI-Suski-Prompt-Vault/data/library.json`
* **缩略图**：`ComfyUI-Suski-Prompt-Vault/data/thumbnails/`

在左栏顶部提供了**导入 / 导出**按钮：
* 导出：直接下载当前的 `library.json` 副本。
* 导入：支持覆盖或增量合并外部 JSON，若遇到同名条目会自动添加递增后缀编号 `(1)` 防止覆盖。

## 安装

进入 ComfyUI 的插件目录，使用 Git 克隆：

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/YourUsername/ComfyUI-Suski-Prompt-Vault.git
```

重启 ComfyUI 即可。无额外第三方 Python 依赖。

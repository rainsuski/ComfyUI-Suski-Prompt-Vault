# ComfyUI-Suski-Prompt-Vault

一个内嵌在 ComfyUI 节点内的三栏提示词管理工作台。主要用于管理个人的高频提示词（支持 Tag 与自然语言双字段）、结构化组合模板，并在画布上直接拼装、排序、切换输出模式和调权。

---

## 设计意图

开发这个插件主要是为了解决个人在日常搓提示词过程中的几个实际操作问题：

1. **保留调试心流，避免来回改坏预设**
   * 提示词调试是一个频繁试错的过程。如果直接改本地词库容易改乱；如果在普通的长文本框里反复加减词和逗号，很容易迷失。
   * 因此设计了“独立草稿”机制：在节点中对词条的修改只作用于当前节点，可以随时一键还原回原始预设；只有测试满意了，再手动点击入库。
2. **支持“穿插式”的模板结构**
   * 很多预设本质上是一套前后呼应的框架（例如“做饭”主题包含：前端的光影/构图，加上后端的动作/姿势）。
   * 传统打包预设一旦载入就变成死板的一整块，无法在中间插入内容。这里将“组”设计为带有几何连线轨道的松散组合，组员载入后，允许将其他独立词条（如角色、道具）直接拖拽插入到组内，连线会自动穿透，既能保持成组的视觉关联，又不限制词序调整。
3. **同一词条兼顾 Tag 与自然语言（NL）工作流**
   * 不同模型对提示词格式偏好不同（例如 Tag 加权词条与完整自然语言句式）。
   * 词库中的每个词条可同时维护 `text`（Tag）和 `nl`（自然语言）两套文本，在中栏可按磁贴粒度独立切换使用哪套文本输出，不必为同一概念维护两份孤立词库。
4. **减少操作弹窗**
   * 拒绝把主流程拆到独立浮窗中，直接将三栏界面挂载在节点主体内（默认尺寸 1120×620），选词、排序、切换模式、改词全部在画布视野内完成。

## 主要功能与交互

### 1. 三栏工作区
* **左栏（提示词库）**：
  * 支持分类筛选、收藏夹筛选、按最近使用优先排序与关键词搜索（同时匹配标题、Tag 与自然语言）。
  * 提供“词条视图”与“组合视图”两种浏览模式。
  * 工具栏支持全局 `Tag / NL` 展示与添加模式切换；处于 `NL` 模式时，有 `nl` 内容的词条展示/复制 `nl` 并默认以 `NL` 状态加入中栏，空 `nl` 词条自动回退为 `Tag`。
  * 排序状态与展示模式自动持久化至浏览器本地缓存。
  * 单击即可加入中栏；若已加入，再次点击则移出。
* **中栏（已选列表）**：
  * 显示当前节点最终参与拼接的词条序列，支持按标题、Tag、自然语言关键词过滤。
  * **模式切换**：鼠标悬停磁贴可点击动作条切换 `Tag / NL` 模式（`nl` 为空时保持 `Tag`）；处于 `NL` 模式的磁贴会在标题行常驻 `NL` 状态徽标。
  * **滚轮调权**：鼠标悬停在磁贴权重标记上，上下滚动滚轮以 `0.1` 为步长增减权重（仅作用于 `Tag` 模式）。
  * **一键静音**：点击眼睛图标可以禁用单条词条，使其不参与最终拼接，便于对照测试。
  * **多选与排序**：按住 `Shift` 可多选词条；支持单条或批量拖拽调整前后顺序。多选后可就地打包新建为组合。
  * **轨道连线**：属于同一个组的成员左侧会显示发光树状连线，中间插入其他词条时以穿透线连接。
* **右栏（词条详情与实时编辑）**：
  * 选中中栏的某个词条后在此显示详情，可直接修改名称、分类和提示词内容。
  * **TAG / NL 切换开关**：提示词标签右侧提供拨动开关，可实时切换当前磁贴的 `Tag` 与 `NL` 编辑视图并同步中栏状态（支持对空 `NL` 内容从零编写）；加减权快捷键（`Ctrl + 滚轮 / 方向键`）仅在 `Tag` 模式下生效。
  * **状态指示**：若 `text`、`nl`、标题或分类与词库预设不一致，会提示“草稿未入库”。
  * **恢复原预设**：放弃当前修改，重置为引用的词库内容。
  * **保存至预设库**：将当前的修改（含 Tag 与 NL 内容）正式同步回 `library.json`。

### 2. 多节点实时同步与防冲突
* 画布上放置多个该节点时，任意节点对词库的修改（增删改）会通过本地 WebSocket 广播，其他节点会自动热更新词库，无需刷新网页。
* 数据写入采用线程锁与临时文件重命名（原子写入），防止并发或意外中断损坏 JSON 文件。
* 针对 ComfyUI Nodes 2.0 做了样式隔离与属性保护，避免破坏侧边栏宽度。

## 节点规格

* **节点类名**：`PromptVaultSelector`
* **显示位置**：`Prompt / Conditioning`

### 输入 / 输出端点

| 插槽 | 名称 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| **Input** | `prepend_prompt` | `STRING` | *(可选)* 前置提示词，拼在所有磁贴最前面 |
| **Input** | `append_prompt` | `STRING` | *(可选)* 后置提示词，拼在所有磁贴最后面 |
| **Input** | `selected_tiles_data`| `STRING` | *(隐藏)* 磁贴序列化数据通道 |
| **Output**| `prompt` | `STRING` | 最终生成的提示词文本 |

### 拼接规则
1. 忽略处于禁用（静音）状态的词条。
2. 磁贴处于 `NL` 模式（`use_nl == true`）时，直接输出 `nl` 原文本，不添加权重包裹；`nl` 为空时跳过。
3. 磁贴处于 `Tag` 模式（`use_nl == false`）时，权重等于 `1.0` 直接输出原内容，不等于 `1.0` 输出格式为 `(prompt:weight)`。
4. 自动合并冗余逗号、修剪多余空格及首尾标点。

## 本地数据与备份

所有数据均保存在插件本地目录下：
* **词库数据**：`ComfyUI-Suski-Prompt-Vault/data/library.json`
* **缩略图**：`ComfyUI-Suski-Prompt-Vault/data/thumbnails/`

在左栏顶部提供了**导入 / 导出**按钮：
* **导出**：支持勾选词条/词组生成轻量压缩分享代码（`v3` 紧凑协议，含分类、标签、组合关联及 `nl` 字段），也支持直接下载完整 `library.json` 备份。
* **导入**：支持粘贴分享代码快速导入（兼容 `v1`/`v2`/`v3` 协议，可自主选择分类与收藏夹归属策略），以及本地 JSON 文件覆盖或冲突预检合并；遇到同名条目会自动添加递增后缀编号 `(1)` 防止覆盖。
